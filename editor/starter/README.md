# Blackbird starter

Resolve a wall-clock timestamp at a known gap or fold without guessing its offset.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Blackbird** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
2
11000
0
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/blackbird) · [View the release](https://github.com/Rahulchaube1/blyx-blackbird/releases/tag/v0.1.0)
